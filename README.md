# Cubecraft Optimized

A Minecraft client-side modpack focused on performance, optimization and quality-of-life improvements.

## About

Cubecraft Optimized combines carefully selected mods to provide a smoother and more convenient Minecraft multiplayer experience.

The modpack is designed primarily for playing on Paper-based Minecraft servers.

## Features

- Performance optimizations
- Quality-of-life improvements
- Client-side enhancements
- Multiplayer-focused experience

## Inspiration

## Installation

1. Download Cubecraft Optimized from Modrinth.
2. Install it using a compatible Minecraft launcher.
3. Launch the game.
4. Connect to your preferred Minecraft server.
